# «Репет»: правила проекта
- Работать только внутри этого репозитория; не создавать production credentials.
- Не выполнять deploy, push, не открывать PR и не менять настройки GitHub.
- Не запускать install scripts из неизвестных репозиториев; не копировать код из reference repositories до проверки лицензии; `.references/` не коммитить.
- Целевая архитектура backend: V2 microservices с page-BFF и domain services; сохранять работоспособность compatibility core `services/core` во время strangler migration.
- Frontend: Next.js, React, TypeScript; предпочитать явные конструкторы и dependency injection.
- Проверки безопасности: deny-by-default, отдельно для каждого ресурса.
- Не принимать от клиентов server-owned поля: `role`, `owner_id`, `organization_id`, `created_by`, `permissions`.
- Бренд UI — только «Репет»; верхняя навигация — только `Главное`, `Сообщения`, `Календарь`, `Задания`.
- Отдельного route `Материалы` нет; файлы находятся внутри уроков, сообщений или заданий.
- Перед передачей результата запускать доступные локальные проверки: `make test` и `make lint`; сообщать, если проверка недоступна.
