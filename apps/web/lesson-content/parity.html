Чётное или нечётное?

Чётное число делится на 2 без остатка. Нечётное даёт остаток 1. Число 0 — чётное.

Сложение: важны только нечётные слагаемые

Нечётные можно собирать в пары: нечётное + нечётное = чётное. Количество чётных слагаемых не меняет чётность суммы.

Пример 1 из источника

Совунья утверждает, что нашла 4 натуральных числа, сумма и произведение которых нечётны. Могут ли её слова быть правдой?

Проверь логическую цепочку: чтобы произведение было нечётным, все четыре числа должны быть нечётными.

4 нечётных слагаемых можно разбить на 2 пары, значит, их сумма чётная. Одновременно оба условия выполниться не могут.

На бумаге: запиши краткое доказательство в два предложения.

Раздел 05 · 8 минут

Чередование по кругу

У соседей по кругу могут чередоваться два вида — но чтобы чередование замкнулось, общее число мест должно быть чётным.

Пример 2

Пример 2 из источника

Нюша написала на доске по кругу 11 натуральных чисел. Бараш утверждает, что найдёт два соседних числа с чётной суммой. Всегда ли это верно?

Посмотри на модель. Нажимай на круги, чтобы менять чётность (Ч/Н), или выбери автоматическое чередование.

11

Почему 11 не получится?

При правильном чередовании после каждого чётного должно идти нечётное, и наоборот. Но замыкая цепочку из 11 мест, встретятся два одинаковых вида.

Одинаковая чётность у соседей означает чётную сумму.

Для повторения

Шпаргалка и мои результаты

Здесь собраны главные идеи из теории. Объясни каждое правило на собственном примере — так оно останется в памяти.

Памятка

Число и пары

Чётное — делится на 2 без остатка: 0, 2, 4, 6, …

Нечётное — остаётся ровно одна фишка без пары: 1, 3, 5, …

Проверка: 17 = 2 × 8 + 1.

Сложение и вычитание

Для суммы важна чётность количества нечётных слагаемых. Чётные не влияют на неё.

Замена +a на −a изменяет итог на 2a, поэтому чётность сохраняется.

Умножение

Если есть хотя бы один чётный множитель, всё произведение чётно.

Произведение нечётно, только когда все множители нечётные.

Чередование и невозможность

Строго чередовать два вида по кругу можно только при чётном числе мест.

Каждый соседний ход ладьи меняет цвет клетки. После нечётного числа ходов к исходной клетке не вернуться.

Мой прогресс по темам

В таблице учитываются проверяемые задачи; свободные доказательства отмечаются по самопроверке.

Для размышления: проверка чётности часто доказывает невозможность. Но если чётность подходит, это ещё не гарантирует, что задача имеет решение.

Как формулировать вопросы

Вместо: «Посчитай всё» — «Нужно ли считать всё, если нас интересует только чётность?»

Вместо: «Это невозможно» — «Какое чётное или нечётное свойство нарушено?»

Вместо: «Запомни правило» — «Покажи правило на парах предметов».

Для доказательства: «Что было бы, если бы такое получилось? Где противоречие?»

Типичные ошибки

0 считают нечётным. Покажи 0 предметов: ни одного предмета без пары.

Путают сумму и произведение. Для суммы считаем нечётные слагаемые; для произведения ищем хотя бы один чётный множитель.

Забывают про замыкание круга. Отметь также соседство последнего и первого.

Задача № 8. Не забудь вычесть Нюшу из числа девочек: спрашивают о подругах, а не обо всех девочках.

Задача № 6. Вычитание не меняет чётность числа: −3 тоже нечётно.
