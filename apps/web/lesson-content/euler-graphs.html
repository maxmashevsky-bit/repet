Круги Эйлера

Когда у предметов есть два или три признака, рисунок помогает не посчитать один предмет дважды.

1. Одна мышь — два признака

Представь мышь с серым хвостом и белым пятнышком. Она принадлежит сразу двум группам. Общая часть двух кругов называется пересечением.

Измени числа

Данные начала взяты из примера 1: 90 мышей с серым хвостом, 70 — с пятнышком, 40 — с обоими признаками.

Подумай: почему нельзя просто сложить 90 и 70? Если все мыши имеют хотя бы один из признаков, значение «ни одного» равно 0.

2. Рассели мышат по областям

Сначала нажми на карточку, затем на область. Можно также перетащить карточку мышью или пальцем. Нажатием на карточку можно выбрать её с клавиатуры.

Рассели все четыре карточки. После каждой попытки появится объяснение.

Тема 2 · 3-й год обучения · страницы 8–10

Увидеть граф

Граф — это точки (вершины) и линии между ними (рёбра). Город и дорога, человек и рукопожатие — всё можно изобразить графом.

1. Построй собственный граф

Выбери одну вершину, затем вторую — появится ребро. Нажатие той же пары ещё раз удалит ребро. Это работает мышью, касанием и с клавиатуры через кнопки.

Нажми вершину 1 и затем вершину 2.

0 = 2 · 0

Сумма степеней = 2 × число рёбер, потому что у каждого ребра два конца.

✎ Нарисуй свой граф и подпиши рядом с каждой вершиной её степень — число выходящих рёбер.

2. Секрет двух подсчётов

На одном рукопожатии участвовали два человека, поэтому при подсчёте рукопожатий «по людям» оно встречается дважды. А если считать только по юношам в задаче «юноши — девушки», каждое рукопожатие учитывается один раз.

Запомни: число рёбер = (сумма степеней всех вершин) : 2. Количество вершин нечётной степени обязательно чётное.

✎ Проверь на своём графе: сложи все степени и раздели сумму пополам. Результат совпал с числом рёбер?

Коротко о главном

Шпаргалка и итоги

Не зубри формулы. Вспоминай, какие предметы ты считаешь один раз, а какие — дважды.

Круги Эйлера

Каждый круг — один признак. Общая область означает, что оба признака встречаются вместе.

Хотя бы A или B = A + B − оба

Если все объекты разделены на две группы, причём часть вне кругов, вычти число внутри кругов из общего количества.

Три признака: A+B+C − AB−AC−BC + ABC. Попарные пересечения включают тройное.

Графы

Вершина — объект, ребро — связь между двумя объектами, степень — число рёбер у вершины.

Сумма степеней = 2 × число рёбер

Отсюда число вершин нечётной степени обязательно чётное.

Полный граф: из n вершин выходит n−1 ребро. Всего n(n−1):2 рёбер.

Мои результаты

✎ В тетради: объясни своими словами, почему пересечение кругов надо вычитать, а число рёбер — делить на два. Для обоих правил придумай по одному примеру.

Простые формулировки

«Общая часть — это те, кто подходит сразу под два описания». «Если просто сложить два круга, общих животных посчитаем дважды». «Каждая дорога выходит из двух городов, поэтому её дважды считают по концам».

Вопросы ученику

«Куда положить мышь с двумя признаками?» «Что останется, если убрать тех, кто любит оба предмета?» «Может ли быть 5 вершин нечётной степени? Почему?»

Частые ошибки

Не вычитают пересечение: попроси обвести один общий объект двумя цветами.

Путают «или» и «и»: физически разложи карточки по областям.

Делят рукопожатия на 2 дважды: спроси, с одной или с обеих сторон посчитали каждое ребро.

Забывают внешнюю область: начни с общего количества предметов.
