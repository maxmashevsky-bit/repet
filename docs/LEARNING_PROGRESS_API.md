# Прохождения и результаты

Ученик определяется только cookie-сессией. Все ресурсы требуют текущего доступа к материалу; другая роль, организация, ученик или урок не получают чужой прогресс. Автор проверяет развёрнутые решения через существующий review API, а не через ученический endpoint.

Префикс: `/api/v1/catalog/lessons/{lessonID}`.

| Метод и путь | Назначение |
| --- | --- |
| POST `/learning-attempts` | `{request_id,restart?:false}`: вернуть последнее прохождение или создать первое; повторный start не создаёт второе активное. `restart:true` создаёт новое только после завершения предыдущего |
| GET `/learning-attempts/{id}` | Сводка, закреплённая опубликованная версия, последние отправленные ответы и уже выданные подсказки. `{id}=current` означает последнее прохождение |
| POST `/exercises/{exerciseID}/attempts` | `{version_id,learning_attempt_id,request_id,answer}`; существующая серверная проверка, сохранение ответа, серверные номер/подсказки/секунды |
| GET `/learning-attempts/{id}/answers?limit=20&offset=0` | Полная собственная история отправок, включая ошибки и ручные результаты; id — UUID |
| POST `/learning-attempts/{id}/exercises/{exerciseID}/hints` | `{request_id}`: сервер выдаёт следующую подсказку и записывает факт выдачи, а не принимает браузерный счётчик |
| POST `/learning-attempts/{id}/complete` | `{request_id}`: завершить, если каждое упражнение имеет отправленный ответ. Ошибки и ожидание проверки не запрещают завершить; результат и состояние сдачи различаются |
| GET `/learning-attempts?limit=20&offset=0` | Собственные прохождения этого урока, от нового к старому |

Каждая изменяющая операция имеет UUID request_id. Повтор с прежней нагрузкой не создаёт второе событие/ответ/подсказку/прохождение. Другая нагрузка с тем же nonce в рамках журнала операции — 409. Состояние в ответе может отражать более позднюю ручную проверку; идемпотентность гарантирует отсутствие повторного эффекта, не замораживание всего JSON навечно. Ошибка сети после записи не теряет ответ; неизменённый повтор renderer использует тот же nonce.

Номер ответа задаётся сервером отдельно для ученика и физического упражнения опубликованной версии, включая повторные прохождения этой версии. Само прохождение имеет отдельный номер по ученику/уроку. Ключ, config и подсказки берутся из неизменяемой закреплённой версии, даже если автор уже опубликовал следующую. Новое прохождение после завершения берёт текущую публикацию. Отзыв доступа к материалу закрывает и старые результаты/повторы.

Время — разница серверных timestamp PostgreSQL. У прохождения это время с начала до завершения (или до запроса состояния), включая закрытую вкладку/перерыв. У ответа — с предыдущей отправки того же упражнения в этом прохождении либо с начала урока. Это не измерение активного внимания ученика; сервер не принимает браузерные duration, timestamps или правильность. Во время открытой страницы счётчик обновляется при серверном действии/обновлении результатов, без притворного локального секундомера.

До пяти подсказок задаются автором в закрытом `answer_key.hints`. Публичное упражнение содержит только hint_count. Текст выдаётся после серверной записи; закрытое пояснение и правильный ответ не используются как подсказка автоматически. Сохранённая попытка содержит снимок числа выданных на тот момент подсказок. Повтор получения подсказки с прежним nonce не расходует следующую.

long_text сохраняется как needs_review и остаётся в очереди автора даже после завершения урока. После проверки те же сохранённые ответы и сводка обновляют результат, не переписывая текст ответа и не создавая новую попытку. История содержит каждую отправку, а не только последнюю ошибку.

Миграция 0008 сохраняет прежнюю exercise_attempts и связывает старые ответы с прохождениями по ученику/версии. Для импортированных ответов неизвестная длительность остаётся 0, начало импортированного прохождения — первая известная отправка. Legacy API без learning_attempt_id остаётся совместимым: сохраняет все ответы и их номера, принимает только текущую публикацию, но такие новые legacy-отправки не участвуют в прохождении и имеют нулевое неизвестное время/подсказки. Новый UI всегда передаёт learning_attempt_id. Автономные HTML мастерской не меняются и сохраняют прежний localStorage.

Восстанавливаются отправленные ответы и результаты; неотправленный текст в поле не является попыткой и автоматически не сохраняется. Завершённое прохождение доступно для чтения; новые ответы требуют нового прохождения. Откат 0008 с сохранёнными learning_attempts намеренно запрещён, чтобы не удалить прогресс.

Контракт: `packages/contracts/openapi/learning-progress.yaml`, подключённый в core-compatibility. Существующие attempt/review пути сохранены.
