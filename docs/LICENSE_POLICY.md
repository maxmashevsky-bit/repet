# License Policy

## Allowed Without Additional Approval

- MIT
- Apache-2.0
- BSD-2-Clause
- BSD-3-Clause
- ISC
- PostgreSQL License for PostgreSQL service usage

## Conditional

MPL-2.0 can be used only after documenting file-level copyleft impact and confirming no source files are copied into incompatible modules.

## Restricted

GPL, AGPL, SSPL, BSL, source-available licenses, unknown licenses, and repositories without a license require legal approval. They must not be linked into the main Go binary or copied into this repository. For these components, create an adapter and document separate-service deployment options.

## Reference Repositories

Reference repositories may be cloned only into `.references/` with shallow clone, pinned tag or commit where practical, and prior review of `LICENSE`, `SECURITY.md`, README, and release metadata. Reference code must not be copied until license review is complete.
