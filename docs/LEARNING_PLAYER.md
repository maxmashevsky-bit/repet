# LearningPlayer (задача 06)

Плеер открывается учеником внутри `/tasks/library/[lessonId]`, без нового верхнего раздела. Использует AppShell, ExerciseRenderer, StudentLearning (результаты), API client и сохранённые прохождения задачи 05. Автономная HTML-мастерская не импортируется в этот движок.

## Содержимое и порядок

Объяснение берётся из summary/content опубликованной версии. Необязательный авторский `example` — числовая прямая с 2–12 пояснёнными кадрами; редактор позволяет создавать его явно. Границы -1000…1000, диапазон до 100; значения кадров внутри границ. JSON проверяется сервером и runtime-валидатором frontend, опубликованный пример закрепляется в immutable version. Если пример не задан, шаг пропускается, выдуманный контент не генерируется. Анимация/ползунки локальные; доступны кнопки, клавиатура, touch и reduced-motion.

Далее по одному отображаются упражнения существующего реестра. Следующее доступно после допустимой сохранённой отправки предыдущего; неверный ответ не запирает урок. Развёрнутое решение может ожидать преподавателя. Финал возможен после отправки всех ответов, включая ожидающие ручной проверки.

## Режимы и сохранение

- `practice`: повторные ответы, серверно записанные подсказки, разбор после допустимой отправки; для развёрнутого ответа — после проверки.
- `exam`: одна новая отправка на упражнение с безопасным повтором nonce, только текущий разрешённый шаг. Сервер скрывает правильность, feedback, reviewed_at и агрегаты до завершения. Подсказки запрещены. Пока есть активная контрольная этого ученика по уроку, endpoint разбора закрыт также для его прежних прохождений; legacy-отправка без run не позволяет обойти запрет. Уже известная история законченной тренировки не стирается.
- Режим фиксируется при старте; меняется только для нового прохождения после завершения. Локальные переключения не меняют активный серверный режим.
- Шаг, изученные блоки, ответы, подсказки и результаты сохраняются сервером. GET current восстанавливает тот же run/версию/шаг после закрытия вкладки. Неотправленный ввод не считается сохранённым: UI показывает это, блокирует Continue и предупреждает об уходе.
- Все существующие правила доступа и серверные время/порядковые номера сохраняются. Истёкший доступ к уроку закрывает также прохождение/разбор.

## Дополнение API

База: `/api/v1/catalog/lessons/{lessonID}/learning-attempts`.

- POST базы: прежние request_id/restart плюс необязательный mode `practice|exam`.
- POST `/{runID}/navigate`: `{request_id, step}`, где step — theory/example/exercise:UUID/results; сервер проверяет prerequisites, replay не возвращает курсор назад.
- GET `/{runID}/exercises/{exerciseID}/solution`: `{exercise_id, available, text}`; только допущенный разбор, не таблица закрытых ключей.
- GET состояния дополнен mode/player_step/theory_seen/example_seen. Для незавершённой контрольной статус ответа `submitted`, feedback пустой и reviewed_at null.

Контракты: `packages/contracts/openapi/learning-progress.yaml`, `learning-catalog.yaml`. Миграция 0009 дополняет, не заменяет календарную lessons. Down запрещён при новых примерах/контрольных/navigation events, чтобы не потерять несовместимые данные.

Практическая совместимость: прежний API практики допускает программную отправку без пошаговой навигации; UI и navigate проверяют порядок. Строгий серверный порядок отправок обязателен для exam. Это интерфейс обучения, не система прокторинга и не блокировка изучения темы в других источниках.
