# Privacy Model

The product is designed as if some students are minors.

## Data Minimization

- No public student directory.
- Student visibility requires confirmed tutor-student relation.
- Phase 1 stores only email, display name, role, relation, invitation, and lesson metadata.

## Default Restrictions

- Communication is allowed only after relation acceptance.
- Access to lessons is restricted to relation participants and admins.
- Tutor notes, parental consent, retention policies, data export, deletion requests, and safeguarding workflows are planned as explicit entities.

## Legal Review Required

This repository does not claim GDPR, COPPA, FERPA, or other legal compliance. Counsel must review lawful basis, parental consent, retention, deletion, export, audit access, incident response, and cross-border processing before production launch.
