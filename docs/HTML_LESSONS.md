# Импорт HTML-уроков (задача 08)

Вход: Задания → Библиотека → HTML-уроки. Собственный UTF-8 HTML/HTM до 512 КиБ; отдельные архивы, executable/PDF и загрузка URL не принимаются. Общий HTTP envelope ограничен RequestBodyLimitByte (по умолчанию 1 МиБ); текст версии и метаданные проверяются сервером. Квота 16 МиБ исходников / 1000 версий на автора. Редактирование создаёт новую версию, оригинал доступен автору как JSON/download. Права: собственный материал, разрешение автора либо открытая лицензия с описанием. Это декларация преподавателя, не юридическая верификация платформой.

## Изоляция

- API приложения никогда не отвечает исходником как text/html. Авторский source endpoint — application/json, доступный только автору. Публичные DTO содержат метаданные и SHA-256, не исходник.
- Отдельный listener `HTML_PREVIEW_ADDR=:8081`, публичный URL `HTML_PREVIEW_PUBLIC_URL=http://html.localhost:8081`. У него нет auth middleware, application API, CORS-grants или cookies. Он не логирует URL-capability. Host header должен совпадать с настроенным preview host.
- URL-capability на 5 минут имеет случайный 256-битный токен; в БД только hash. Он привязан к пользователю и точной версии/назначению. ACL проверяются при выдаче и каждом открытии, включая активную связь с учеником. Истечение/отзыв запрещают повторную загрузку; уже загруженный в браузер документ невозможно отозвать задним числом.
- Preview требует отличающегося hostname от каждого application origin. Для production нужен HTTPS и предпочтительно отдельный registrable domain без auth-cookies. `html.localhost` предназначен только для локальных браузеров с loopback localhost resolution; при иной поддержке настроить отдельный локальный hostname, не использовать hostname приложения.
- Iframe и HTTP CSP: только sandbox allow-scripts, **без allow-same-origin**. Оpaque origin запрещает parent DOM, document.cookie, localStorage. CSP запрещает fetch/XHR/WebSocket, workers, frames, объекты, формы и внешние изображения/скрипты/стили; допускаются inline JS/CSS и data-изображения/шрифты. Нет popup/top-navigation/download разрешений. Referrer не передаётся.
- Parent CSP frame-src допускает только preview origin, включая навигацию iframe. `HTML_PREVIEW_PUBLIC_URL` передаётся в frontend build args, а не только runtime env. При смене preview URL нужно пересобрать web.
- Основы модели: [HTML sandbox](https://html.spec.whatwg.org/dev/iframe-embed-object.html), [CSP sandbox](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/sandbox). Sandbox не является антивирусом или CPU-квотой: вредоносный цикл может перегрузить процесс браузера. Не открывать непроверенные файлы скачиванием вне sandbox.

## Библиотека и задания

HTML-каталог использует существующие courses/topics, роли, классы/направления/сложность и видимость курса. Только автор меняет/публикует/архивирует исходник. Ученик видит опубликованную версию при опубликованных курсе и всех предках темы; черновики недоступны. Фильтры и пагинация выполняются backend.

Назначение использует существующее текстовое задание с отдельной html_assignment_links, а не ложное interactive exercise_attempt. Оно фиксирует последнюю публикацию; новый импорт/публикация/архив не меняют выданный snapshot. Доступ только паре назначения с активной связью. Отчёт ученика и оценка преподавателя — ручные. Скрипты iframe/postMessage не записывают попытки или баллы в приложении.

## Конвертация и ограничения

«Конвертировать в упражнения» создаёт отдельный черновик LearningLesson с безопасно извлечённым текстом и ссылкой происхождения на HTML-версию. Scripts/styles, ключи и результаты JS не переносятся. Конвертация и provenance создаются одной транзакцией. Преподаватель вручную проверяет текст, добавляет упражнения/ключи/подсказки/разборы в существующем редакторе. Конвертированный урок без упражнений нельзя публиковать. После публикации работает обычный ExerciseRenderer и серверная статистика.

Старые HTML могут не работать без CDN, storage, сетевых запросов, popup/alert или same-origin. Встроенные открытые ответы в их JavaScript остаются читаемыми ученику внутри документа, поэтому такой формат не подходит для защищённой контрольной. Сторонние библиотеки/изображения должны быть встроены с разрешённой лицензией и в пределах лимита. Layout самого документа зависит от автора; shell адаптивен, исходник не переписывается. Извлечение текста для конвертации не гарантирует перенос рисунков и структуры: это ручной workflow, не автоматическая миграция интерактивов.

HTML — ограниченный версионируемый учебный документ, хранимый транзакционно в PostgreSQL аналогично содержимому lesson_versions. Это не универсальное файловое хранилище. S3-compatible ObjectStorage из ADR 0004 остаётся production-границей для больших файлов/PDF/вложений; текущий срез не вводит публичный filesystem adapter и не заявляет наличие AV scanning.

## Endpoints

- GET/POST `/api/v1/html-lessons`: каталог / импорт.
- GET `/api/v1/html-lessons/{id}`: метаданные текущей доступной версии; version_id — версия, assignment_id — snapshot назначения.
- GET/POST `/{id}/versions`: история автора / новая неизменяемая версия; request_id обеспечивает replay, изменённый payload с тем же nonce даёт 409.
- POST `/{id}/publish`: version_id должен быть текущей версией; курс и дерево темы опубликованы.
- POST `/{id}/archive`: только автор.
- POST `/{id}/preview`: version_id и необязательный assignment_id; возвращает URL-capability.
- GET `/{id}/source?version_id=…`: только автор, JSON.
- POST `/{id}/assign`: student_id, due_at, request_id; идемпотентно.
- POST `/{id}/convert`: version_id; отдельный ручной черновик.
