# Банк упражнений

Задания → Библиотека → Банк упражнений. Только преподаватель. Используются существующие native уроки, ExerciseRenderer, закрытые ключи, LearningPlayer и назначения; календарная таблица `lessons` не меняется.

## Материалы и права

На странице своего опубликованного урока: «Добавить упражнение в банк». Выбрать упражнение, класс5–11, направление, тему/подтему, экзаменационный номер для ОГЭ/ЕГЭ, источник, атрибуцию и условия использования. Направления: `school`, `olympiad`, `oge`, `ege_basic`, `ege_profile`; предмет пока только `math`. Сложность, условие, тип, изображения, hints и решение берутся из опубликованного снимка, не из черновика. Решения доступны отдельным tutor-only endpoint, не в списке.

Номер1–100 — метаданные автора, не утверждение о структуре официального экзамена определённого года. В репозиторий не добавлена вымышленная официальная база. Автоматические проверки используют собственные небольшие демонстрационные примеры.

Банк сохраняет неизменяемую запись конкретной публикации. Исправление задания: новая публикация исходного урока и новая запись банка. Старый snapshot сохраняется для воспроизводимости. Доступ повторяет курс: собственные материалы либо опубликованный курс с visibility `organization`; чужие приватные материалы недоступны. Архивирование курса/темы/урока убирает источник из нового выбора. Условия лицензии и разрешений подтверждает преподаватель; сервис не проверяет достоверность прав автоматически.

## Поиск и подборки

Фильтры: направление, класс, номер, тема, подтема, сложность, тип ответа(API). Поиск по русскоязычным словам условия/темы/источника, не поиск по произвольной части слова. `limit=1..100`, `offset=0..100000`, стабильный порядок created_at/id. GIN FTS, составной category/grade/number и topic/subtopic индексы. Facets учитывают остальные фильтры и доступ; подтемы сужаются темой.

Выбрать до100 упражнений, в том числе из разных уроков, изменить порядок кнопками, указать название и собственный опубликованный курс/тему, сохранить. Создаётся приватный native `assignment_only` урок и отдельная неизменяемая подборка: собственные exercise keys, закрытые ключи, hints, media и provenance с авторством/лицензией. Курс и тема назначения должны быть опубликованы; скрытый предок темы не допускается. Копия не появляется в каталоге ученика даже по прямому ID. Через назначение ученик получает только закреплённую версию; последующие правки оригинала или производного черновика не меняют её.

«Мои подборки» → выбор учеников → срок → тренировка/контрольная → назначение до50 подтверждённым ученикам. Режим контрольной пока использует существующий07 режим без таймера; полноценные пробники — задача11. Можно использовать существующие результаты/повторение из задания.

Создание подборки идемпотентно по `request_id` и телу. Batch назначений сохраняет request payload и детерминированные child request IDs; повтор не создаёт дублей, изменённое тело с тем же nonce даёт409. Не заявляется общая атомарность50 назначений: результат каждого ученика содержит assignment либо явную ошибку. Повторить тот же запрос безопасно; уже успешные назначения сохраняются. Начальная проверка чужого/неподтверждённого ученика отклоняет весь новый batch. Отзыв связи в процессе может дать частичный результат. Приватные данные не возвращаются в ошибке.

## API

- `GET/POST /api/v1/exercise-bank`
- `GET /api/v1/exercise-bank/facets`
- `GET /api/v1/exercise-bank/{bankID}`
- `GET /api/v1/exercise-bank/{bankID}/answer-key` — только tutor с доступом к источнику
- `GET/POST /api/v1/bank-collections`
- `GET /api/v1/bank-collections/{collectionID}` — только владелец
- `POST /api/v1/bank-collections/{collectionID}/assign`

Контракт: `packages/contracts/openapi/exercise-bank.yaml`. Ответы серверной проверки и прогресс — существующие API назначений и learning-attempts. Server-owned author/org/access_mode не принимаются в body. Приватные PDF-изображения наследуют ресурсные ACL скопированного упражнения.

Browser: `apps/web/tests/exercise-bank.e2e.mjs`; используется `REPET_E2E_URL`, `REPET_PLAYWRIGHT_MODULE`, `REPET_CHROME_PATH`. Проверяет реальную регистрацию в банке/фильтры/подборку/сбой и retry/двух учеников/закреплённые ответы/mobile. Результаты и ограничения актуальной проверки находятся в CODEX_PROGRESS.md; этот список сценариев сам по себе не означает PASS.
