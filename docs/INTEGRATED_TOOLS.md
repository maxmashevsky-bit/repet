## Связи

- В карточке рабочего плана выбирается «Аккаунт ученика» из действующих подтверждённых связей этого преподавателя. Нового ученика нужно пригласить, а ученик подтверждает связь; учитель не создаёт чужую учётную запись без согласия. Для приглашения из карточки есть ссылка на существующую форму.
- В «Типовой неделе» задаётся период и выполняется «Перенести в календарь». Создаются обычные lessons и уведомления ученику. Повтор не дублирует занятия; изменения плана не переписывают прошлый согласованный календарь. Пауза и отсутствие аккаунта отражаются отдельными счётчиками. См. TUTOR_PLANNER.
- Из чата можно скачать разрешённый файл, раскрыть условие задания, перейти к нему, открыть опубликованный native урок. Ссылки не дают новых прав. Форматы PNG/JPG/TXT ограничены и проверяются сервером; PDF по-прежнему импортируется через PDF workflow, не через chat.
- Текстовая работа открывается отдельной страницей для обеих ролей, в том числе из прежних уведомлений `/tasks?task=...`. Ученик отправляет ответ, преподаватель проверяет, ученик получает результат.

## Старые HTML И Достоверные Результаты

В мастерской у каждого урока есть «Добавить в мою библиотеку» и «Создать проверяемые упражнения». Исходник загружается по allowlisted slug только преподавателю; права использования подтверждаются явно. Безопасный импорт сохраняет оригинал/версию. Конвертация открывает отдельный native черновик с извлечённым текстом; преподаватель составляет и проверяет упражнения/закрытые ответы, затем публикует и назначает. Дальнейшие ответы проверяет сервер, они попадают в аналитику и повторение.

Старые JS/localStorage баллы и прежняя история автономных HTML **не импортируются как достоверные результаты**. Автоматически восстановить их проверенную историю нельзя: сервер не наблюдал попытки и не проверял ответы. Это не обходится postMessage из iframe. HTML остаётся доступен в исходном формате, а native путь даёт полноценную проверяемую статистику новых прохождений. OCR PDF остаётся ручным этапом; нет обещания безошибочного извлечения или официальных экзаменационных баллов.

## Локальный Запуск

Стандартный запуск остаётся `docker compose up --build` из README, с сохранением volumes. Нельзя удалять volumes ради обновления. Текущая тестовая интегрированная сборка запущена на `http://127.0.0.1:3020` в собственных repet-messages15-web/api, с общей актуальной frontend/API версией. После первого среза16 используются образы repet-tenants16-web/api: добавлены личные настройки преподавания и усилен scope standalone решений. Это не завершение всего16. База repet_integration_preview на отдельном repet-integration-postgres и named volume repet-integration-postgres-data содержит только данные этой development preview; старый пользовательский том repet_postgres-data не изменялся. Она не является автоматическим переносом аккаунтов из прежних баз.

Проверки — отдельные repet_integration_checks_v2/race/migrations, не пользовательская БД. Доказательства и ограничения в CODEX_PROGRESS; не запускать fixture-тесты на реальных данных. Публичное размещение, HTTPS/backup приёмка и полная многопользовательская задача16–19 этим запросом не объявляются готовыми.
