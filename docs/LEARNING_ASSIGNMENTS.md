# Интерактивные домашние задания (07)

В разделе «Задания» преподаватель выбирает ученика, ищет опубликованный материал и назначает урок целиком либо отмеченные упражнения. Подборку можно сохранить в «Мои наборы» и назначить позднее. Срок обязателен; занятие календаря и режим тренировки/контрольной выбираются отдельно. Текстовые задания и их прежний цикл submit/grade сохранены.

## Данные и доступ

Миграция 0010 добавляет assignments.kind (text/material), material_assignments, exercise_sets и learning_attempts.assignment_id. Назначение копирует ID sealed версии, ключи выбранных упражнений и режим; публикация новой версии, изменение или удаление набора не меняют выданную работу. Подборка состоит из 1–200 упражнений одной версии одного урока, в авторском порядке. Наборы из разных уроков не объединяются в искусственный новый курс.

Назначать может только tutor своему активному ученику в своей организации; материал должен быть доступен этому преподавателю. Calendar lesson проверяется по той же организации, преподавателю и ученику, отменённое занятие не принимается. Связь хранится отдельно от календарной lessons и не меняет её модель.

Назначение даёт конкретному ученику доступ только к своему snapshot/подборке, а не ко всему курсу. Архивирование каталога не стирает выданные работы. Блокировка/окончание связи tutor/student или архивирование назначения закрывает выполнение и результаты. Другой ученик, преподаватель, организация и admin не получают обходной доступ к material-ресурсу. Автор общего материала не видит чужие назначенные ответы и не может проверять их вместо назначившего преподавателя.

## Выполнение и результат

Ученик видит назначение на главной и в `/tasks`, выполняет его в `/tasks/[assignmentId]` через существующий LearningPlayer. Один assignment имеет одно выделенное прохождение, независимое от свободной тренировки и других назначений. В состояние/проверку/подсказки попадают только выбранные упражнения; нельзя отправить ответ за исключённое упражнение или подменить student/result/time/mode.

После отправки всех упражнений completion переводит назначение в done либо submitted, если есть ручная проверка. Done означает завершение работы, а не отсутствие ошибок. Проверка развёрнутого решения назначившим преподавателем синхронизирует статус. Результаты содержат текущие ответы, ошибки, число отправок по каждому упражнению именно в этом назначении и историю с пагинацией. Глобальный порядковый номер exercise_attempts из задачи 05 сохранён; assignment counts рассчитываются отдельно.

Контрольная сохраняет политику 06: правильность, feedback и ошибки закрыты до завершения. Отправки/подсказки через другую назначенную или свободную тренировку того же урока не обходят активную контрольную. Срок хранится сервером, сравнивается с серверным временем при назначении; поздняя сдача допускается, время фактического завершения сохраняется сервером.

Повторение создаётся отдельно, с новым сроком, прежним snapshot/подборкой/режимом и repeat_of. Оно не сбрасывает старую историю. Создание assignment, повторение и старт используют nonce; повтор с изменённым payload даёт 409. Сохранение ответа/навигации/завершения переиспользует идемпотентный API 05–06.

## API

База `/api/v1`:

- POST `/assignments/material`: request_id, student_id, lesson_id **либо** set_id, необязательные exercise_ids (пусто = весь урок), due_at, calendar_lesson_id, mode.
- GET `/assignments/{id}`: прежний Assignment плюс kind/material.
- POST `/assignments/{id}/learning-attempt`: request_id; начать/продолжить своё назначение.
- GET `/assignments/{id}/learning-results?limit=20&offset=0`: assignment, version, state, history, exercise_stats; только назначивший tutor и назначенный student.
- POST `/assignments/{id}/repeat`: request_id, due_at, необязательный calendar_lesson_id.
- GET/POST `/exercise-sets`, PUT/DELETE `/exercise-sets/{id}`: только собственные наборы tutor. UI создаёт, выбирает и удаляет наборы; PUT доступен через API.
- Прежние catalog learning-attempt navigate/answer/hint/complete/solution продолжают работать для выделенного assignment run с дополнительным ACL/ограничением подборки.
- PUT `/catalog/lessons/{id}/attempts/{attemptId}/review`: также доступен назначившему tutor для его назначенного развёрнутого ответа, после завершения контрольной.

OpenAPI: `packages/contracts/openapi/material-assignments.yaml`. Клиентские server-owned поля отклоняются decodeJSON. Закрытые ключи не включаются в DTO; только разрешённый после попытки разбор запрашивается прежним отдельным endpoint.
