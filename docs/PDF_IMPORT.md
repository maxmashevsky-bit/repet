# PDF в интерактивный урок

Задания → Библиотека → Импорт PDF. Только преподаватель и только собственные либо разрешённые материалы. Никаких платных AI-вызовов и автоматической публикации.

## Рабочий процесс

1. Загрузить PDF, указать источник, основание использования и лицензию/разрешение. Максимум 5 МиБ и 10 страниц; шифрование не поддерживается.
2. Дождаться фонового извлечения. Сверить текст, исходные числа и нумерацию с изображением каждой страницы. Оригинальный текст не перезаписывается; исправления хранятся отдельно.
3. Для страницы без текстового слоя выполнить отдельную ручную расшифровку и подтвердить её. Статус `ocr_required` означает отсутствие текста, а не выполненное OCR. Автоматический OCR пока не подключён. Плохой, но непустой текст тоже может нуждаться в расшифровке.
4. Встроенные bitmap-изображения извлекаются отдельно. Векторные схемы видны на изображении страницы; нужный фрагмент можно сохранить отдельным рисунком через координаты области. В ученика нельзя автоматически отправить полную исходную страницу с возможными ответами.
5. Выбрать свой курс и тему, создать черновик. Классы/направление наследуются от курса и редактируются существующим конструктором. Разделение по нумерованным условиям и предложенный тип ответа — только редактируемые подсказки, не гарантированное распознавание. Предлагается до50 условий на страницу; длинное условие не обрезается и требует ручного разделения перед добавлением (лимит упражнения20КБ).
6. Добавить условия и выбранные рисунки в упражнения, уточнить тип, закрытые ответы, подсказки и разборы. Текст объяснения и анимированный пример используют существующий редактор. Решения и hints не включаются в публичный JSON упражнения.
7. Сохранить, просмотреть через общий ExerciseRenderer и подтвердить проверку текущей версии PDF. Сервер требует проверенных страниц и хотя бы одного упражнения. Публикация остаётся отдельным явным действием. Любая правка урока/упражнений меняет revision и отменяет разрешение публикации; правка текста страницы также сбрасывает проверку связанных черновиков.
8. Опубликованный урок доступен в библиотеке и назначается обычным механизмом интерактивных домашних заданий. Ответы проверяет сервер, развёрнутые решения — преподаватель. Старые версии и закреплённые рисунки сохраняются.

## Безопасность и хранение

- ObjectStorage interface + приватный filesystem adapter: каталог 0700, файлы 0600, случайные ключи, `os.Root`, отсутствие публичного файлового пути и перезаписи объектов. У web нет mount хранилища. S3 остаётся production-целевой реализацией ADR0004.
- Оригиналы являются карантинными источниками: только авторская загрузка как attachment `application/octet-stream`, без inline PDF viewer. Сайт никогда не исполняет JS PDF. Это не антивирусная сертификация; исходник не становится общим вложением и не должен обходить будущий общий upload/scanning pipeline.
- Poppler выполняется отдельным процессом в контейнере без DB, cookies, секретов, публичных портов и внешней сети: nonroot, read-only, cap_drop ALL, no-new-privileges, tmpfs128МиБ, memory512МиБ, cpu1, pids64. Внутренняя сеть соединяет только API и extractor. Поддерживать образ и пакеты обновлёнными; эта конфигурация не является публичным deployment.
- Один документ на worker, дедлайн40с, ограниченные страницы/текст/пиксели/вывод. Приложение повторно декодирует и кодирует только PNG; активные PDF/SVG/HTML не выдаются в качестве картинок.
- Не более100 импортов и100МиБ исходников на автора; суммарно исходники+производные объекты до512МиБ. Не более64 порядковых номеров рисунков на импорт. Эти стартовые лимиты не заменяют мониторинг диска.
- У исходников/извлечённых страниц/рисунков неизменяемые записи. Проверки доступа выполняются на каждый запрос. Другой преподаватель не читает чужой импорт. Ученик видит только рисунки, включённые в доступную публикацию, его закреплённое прохождение или выбранные упражнения доступного назначения. Полные страницы и исходники ученикам закрыты.
- Durable очередь PostgreSQL с SKIP LOCKED и двухминутным lease; перезапуск восстанавливает незавершённую обработку. Транспортные сбои повторяются с задержкой15с, максимум3 попытки. Повтор upload с тем же request_id возвращает тот же импорт, конфликт содержимого —409.
- Удаление сохранённых оригиналов/версий и общая сборка orphan objects пока не предоставлены. При отмене/ошибке загрузки незакоммиченные объекты очищаются отдельным ограниченным контекстом. Неопределённый COMMIT сначала разрешается через тот же author lock и проверку metadata: закоммиченный источник не удаляется. Если БД недоступна и исход неизвестен, объект сохраняется; последующий reconciler должен сверять metadata и private storage. Backup обязан включать БД и объекты вместе. Подготовка автоматического backup/restore входит в17.

## Локальная конфигурация

Compose добавляет `pdf-extractor` и volume `learning-objects` без публичного порта worker. При нативном запуске API установить `PDF_EXTRACTOR_URL` на приватный worker и `OBJECT_STORAGE_PATH` на отдельный0700 каталог. Без URL импорт отключён, остальной core работает. Не указывать публичный или пользовательский URL extractor. Настройки принадлежат оператору, клиент не передаёт URL.

Poppler вызывается как системная утилита, не встраивается в Go binary. При распространении образа соблюдать лицензии пакетов, включая GPL-условия Poppler, и предоставление соответствующих исходников; пользовательские PDF не становятся кодом Poppler. Новых JS-зависимостей нет.

## HTTP API

Контракт: `packages/contracts/openapi/pdf-imports.yaml`. Все операции требуют session cookie; mutation сохраняет действующие Origin/CSRF проверки.

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/v1/pdf-imports` | JSON upload base64,202, immutable source + idempotency nonce |
| GET | `/api/v1/pdf-imports?limit=20&offset=0` | Только свои импорты, пагинация |
| GET | `/api/v1/pdf-imports/{id}` | Статус, raw/corrected text, metadata и рисунки |
| GET | `/api/v1/pdf-imports/{id}/source` | Приватное скачивание оригинала |
| PUT | `/api/v1/pdf-imports/{id}/pages/{number}` | Ручная сверка/расшифровка страницы |
| POST | `/api/v1/pdf-imports/{id}/figures` | Проверяемый crop страницы в новый PNG |
| POST | `/api/v1/pdf-imports/{id}/lessons` | Черновик native lesson + provenance одной транзакцией |
| GET | `/api/v1/pdf-assets/{id}` | PNG с ресурсным ACL |
| GET | `/api/v1/catalog/lessons/{id}/pdf-source` | Авторская связь с источником и revision |
| POST | `/api/v1/catalog/lessons/{id}/pdf-review` | Подтверждение текущего revision, не публикация |

Сохранение/публикация/назначение/прохождение используют существующие catalog, material-assignments и learning-attempts API. `Exercise.media` содержит максимум4 объекта `{asset_id,alt}` без произвольных URL и без правильных ответов.

## Проверки

Синтетический fixture создаётся `python3 scripts/create-pdf-test-fixture.py` (reportlab + Pillow). Это собственные три задания и вторая bitmap-страница без text layer; не официальный экзаменационный материал. Файл выводится в игнорируемый `tmp/pdfs`. E2E принимает другой путь через `REPET_TEST_PDF`.

```sh
TEST_DATABASE_URL=postgres://... make test
TEST_DATABASE_URL=postgres://... make race
make lint
cd apps/web
node --experimental-strip-types --test tests/*.test.mjs
REPET_E2E_URL=http://127.0.0.1:3011 node --test tests/pdf-import.e2e.mjs
```

Интеграционные проверки запускать только на отдельной синтетической БД. Актуальные результаты и ограничения среды записываются в CODEX_PROGRESS, не выводятся из одного наличия тестов.
