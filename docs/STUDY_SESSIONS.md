# Тренировки и пробные экзамены

Внутри «Заданий» открыт раздел `/tasks/study`. Верхних разделов по-прежнему четыре.

## Сценарий

Преподаватель собирает собственную лицензированную подборку банка, создаёт программу: направление ОГЭ/ЕГЭ база/профиль, год, время, инструкцию и номера с количеством задач и баллами. Черновик не виден ученику. Публикация проверяет достаточность разных исходных упражнений; новая редакция создаётся отдельной версией.

Ученик выбирает программу. Тренировка допускает выбор темы/количества, повторные ответы, подсказки и разборы существующего LearningPlayer. Общая школьная/олимпиадная практика остаётся доступной в библиотеке. Пробник позволяет переходить между номерами, исправлять сохранённые ответы и сдавать с пропусками. При повторном открытии восстанавливаются ответы и серверный срок. Результат содержит верные/неверные/непроверенные/пропущенные задания отдельно. Ошибки и пропуски можно отправить в отдельную тренировку; непроверенные решения ошибками не считаются.

## API и модель

- `GET/POST /api/v1/exam-specifications`, `GET /api/v1/exam-specifications/{id}`, `POST .../{id}/publish`, `POST .../{id}/archive`.
- `GET/POST /api/v1/study-sessions`, `GET /api/v1/study-sessions/{id}`.
- `GET /api/v1/study-reviews` — очередь назначенного автора для ручной проверки; только последние развёрнутые ответы после сдачи.
- Отправка/переход/завершение/подсказки/разборы используют существующие `catalog/lessons/{lesson}/learning-attempts/{run}` и exercise attempts API. Ручная проверка — существующий `PUT catalog/lessons/{lesson}/attempts/{answer}/review`.

Контракт: `packages/contracts/openapi/study.yaml`. Миграция 0015 не заменяет календарную `lessons` и использует native learning_attempts/exercise_attempts. Снимок подборки, набор выбранных ключей, коэффициенты баллов и версия программы неизменяемы. SHA-256 от версии/seed/логического источника задаёт воспроизводимый порядок; разные версии одного исходного упражнения не дублируются в варианте.

## Границы доверия

Роль/автор/ученик/проверяющий/время/результат не принимаются из браузера. До сдачи exam ответы проецируются как submitted без правильности, комментариев, баллов или подсказок. Строгий runtime parser отклоняет раскрытые результаты активного exam. Срок вычислен из серверного started_at; запись ответа после deadline запрещена PostgreSQL trigger. Состояние и очередь преподавателя завершают просроченные экзамены независимо от открытой вкладки. API времени использует часы БД, браузерный таймер — лишь отображение.

Каждый ресурс проверяет организацию, владельца и активную связь/доступ курса. Подборка остаётся assignment_only и не раскрывается общей библиотеке. Развёрнутые решения требуют активной связи с проверяющим. У ученика только собственная история; чужой ID не открывает прохождение. Запросы создания/ответа/перехода/сдачи идемпотентны; повтор nonce с иными данными отклоняется.

## Ограничения

Это авторские учебные варианты, не сертифицированные официальные экзамены. Баллы вычисляются по закреплённым правилам: правильный ответ получает все баллы номера, неверный/пропуск — ноль; развёрнутый ответ ожидает решения преподавателя. Частичных баллов и официальной таблицы перевода нет. Год/структура/время/инструкция версионируются и не объявляются официальными нормативами.

Максимум 100 задач, 100 разных номеров, 8 часов; запас заданий определяется подборкой. Автоматического OCR/AI или импорта официальных материалов здесь нет. Старые HTML-уроки не становятся доверенными экзаменами автоматически. Истёкший результат материализуется при следующем обращении к старту/истории/состоянию/очереди проверки, а не отдельным background scheduler; поздние ответы блокируются независимо от этого.
