# Design System: Warm Study

Статус: утверждено пользователем.

## Визуальное настроение

- Тёплое, спокойное, профессиональное.
- Минималистичный интерфейс с мягким учебным характером.
- Без ярких агрессивных цветов.
- Подходит для кабинета ученика, сообщений, заданий, календаря, прогресса и настроек.

## Основная палитра

| Token | Использование | HEX |
| --- | --- | --- |
| `background` | Главный фон приложения | `#FAF7F2` |
| `surface` | Карточки, панели, диалоги | `#FFFFFF` |
| `text` | Основной текст | `#2F2A24` |
| `muted` | Вторичный текст, подсказки, metadata | `#7A7168` |
| `primary` | Основной акцент, кнопки, active states | `#6F8F72` |

## Дополнительная палитра

| Token | Использование | HEX |
| --- | --- | --- |
| `primary-hover` | Hover основной кнопки | `#58735B` |
| `border` | Границы, разделители, inputs | `#E8E1D8` |
| `success` | Выполнено, хороший прогресс | `#5E9C76` |
| `danger` | Ошибки, destructive actions | `#C76D62` |
| `warning` | Предупреждения, внимание | `#D8A84E` |
| `terracotta` | Сроки и поддержка создателя | `#B96852` |

## Типографика

```css
font-family: "Manrope", "Inter", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

Выбранные шрифты должны качественно отображать кириллицу. Интерфейсный текст — настоящий HTML-текст, а не часть изображения.

## CSS tokens

```css
:root {
  --background: #FAF7F2;
  --surface: #FFFFFF;
  --text: #2F2A24;
  --muted: #7A7168;
  --primary: #6F8F72;
  --primary-hover: #58735B;
  --border: #E8E1D8;
  --success: #5E9C76;
  --danger: #C76D62;
  --warning: #D8A84E;
  --terracotta: #B96852;
  --font-sans: "Manrope", "Inter", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
}
```

## Правила UI

- Главные страницы используют `background`.
- Карточки и рабочие области используют `surface`.
- Primary actions используют `primary`.
- Основной текст использует `text`.
- Время, hints и descriptions используют `muted`, сохраняя достаточный контраст.
- Borders тонкие и используют `border`.
- Отступы щедрые, углы мягко скруглены, визуальный шум минимален.
- Терракотовый используется дозированно для важных сроков и поддержки создателя.
- Не использовать неон, glassmorphism, тяжёлые градиенты и emoji вместо UI-иконок.
