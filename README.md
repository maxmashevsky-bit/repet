# Репет

«Репет» — приложение для занятий преподавателя и ученика. Рабочий API находится в `services/core` (Go/PostgreSQL), интерфейс — в `apps/web` (Next.js). Каталоги BFF и domain services описывают целевые границы миграции и пока не запускаются как отдельные сервисы.

## Запуск

Для собственного сервера: [инструкция запуска](docs/SERVER_LAUNCH.md), единый корневой `Dockerfile` и `compose.prod.yml`. Архив для переноса: `sh scripts/package-server.sh`. Это подготовка без публичного развёртывания; домены и SMTP заполняются владельцем. Ниже описан локальный development-запуск.

Требуются Docker и Docker Compose. В корне репозитория:

```sh
git clone git@github.com:maxmashevsky-bit/repet.git
cd repet
docker compose up --build
```

Откройте http://127.0.0.1:3000/register. API автоматически применяет миграции к пустой базе. После регистрации подтвердите почту по ссылке из письма. Локально письма подтверждения и восстановления пароля доступны в Mailpit: http://127.0.0.1:8025; это тестовый почтовый сервер, он не отправляет письма в интернет. Для реальной отправки настройте SMTP по [инструкции сервера](docs/SERVER_LAUNCH.md).

Подтверждение включено по умолчанию. Только для изолированных development/E2E окружений его можно явно отключить через `REQUIRE_EMAIL_VERIFICATION=false`; production это запрещает. `APP_PUBLIC_URL` должен совпадать с адресом, по которому открыт сайт, иначе сессия другого hostname не будет доступна по ссылке из письма.

Compose слушает только loopback. Если стандартные порты заняты, можно задать `POSTGRES_PORT`, `API_PORT`, `WEB_PORT`, `SMTP_PORT` и `MAILPIT_PORT` перед командой. Остановка: `docker compose down` (данные PostgreSQL сохраняются в volume).

Для локальной разработки без контейнеров приложения нужны Go 1.25+, Node.js 22+ и pnpm 11.19.0:

```sh
cp .env.example .env
docker compose up -d postgres mailpit
(cd apps/web && pnpm install --frozen-lockfile --ignore-scripts)
set -a; . ./.env; set +a
make api
```

В другом терминале запустите `make web`. Next.js направляет `/api/v1/*` в Go API через `API_INTERNAL_URL`; по умолчанию это `http://127.0.0.1:8080`.

## Основной сценарий

Все инструменты преподавателя доступны с главной страницы: «Ученики и план», «Библиотека», «Импорт PDF», «Банк упражнений», «Пробники», «Успеваемость», «Повторение», «Семья». Связь рабочего плана с аккаунтами/календарём, вложения чата и проверяемая конвертация старых HTML описаны в [INTEGRATED_TOOLS.md](docs/INTEGRATED_TOOLS.md).

1. Зарегистрируйтесь как преподаватель. На главной создайте приглашение по email ученика и передайте полученную ссылку.
2. Ученик регистрируется с тем же email, открывает ссылку и принимает приглашение.
3. Преподаватель создаёт занятие в календаре и задание в разделе «Задания». Ученик видит их, отправляет ответ, преподаватель выставляет баллы и комментарий.
4. Обе стороны видят уведомления и могут писать в созданном диалоге.

## Проверки

Прогресс «Репет 2.0»: [трекер](docs/CODEX_PROGRESS.md), [roadmap](docs/REPET_ROADMAP.md), [правила следующих запусков](docs/CODEX_WORKFLOW.md). Перед следующей задачей прочитайте workflow. Сводка без установки зависимостей: `sh scripts/repet-progress.sh`.

Для этих команд нужны Go 1.25+, Node.js 22+, pnpm 11.19.0 и установленные зависимости `apps/web`.

```sh
(cd apps/web && pnpm install --frozen-lockfile --ignore-scripts)
make test
make lint
make race
make typecheck
make web-build
```

Интеграционный тест с реальной PostgreSQL запускается при заданном `TEST_DATABASE_URL`:

```sh
cd services/core
TEST_DATABASE_URL='postgres://tutor:tutor@127.0.0.1:5432/tutor_platform?sslmode=disable' go test ./internal/store -run TestProductFlowPostgres -count=1
```

Контракт текущего API: `packages/contracts/openapi/core-compatibility.yaml`. Backend учебного каталога и пример API-сценария описаны в [LEARNING_CATALOG_API.md](docs/LEARNING_CATALOG_API.md); его контракт подключён из `learning-catalog.yaml`. Настройки развития архитектуры находятся в `docs/`.

Импорт собственных HTML: Задания → Библиотека → HTML-уроки. [Изоляция, версии и ограничения](docs/HTML_LESSONS.md). Локальный preview использует отдельный hostname `html.localhost` и порт `HTML_PREVIEW_PORT` (8081); при смене URL пересоберите frontend. Публичное размещение не выполняется автоматически.

PDF → интерактивный урок: Задания → Библиотека → Импорт PDF. [Ручная сверка, закрытые ответы, обработчик и ограничения](docs/PDF_IMPORT.md). Compose использует приватный worker без публичного порта и отдельный volume исходников/рисунков.

Банк упражнений5–11: Задания → Библиотека → Банк упражнений. [Метаданные, источники, закрытые решения, подборки и массовые назначения](docs/EXERCISE_BANK.md).

Тренировки и пробники: Задания → Тренировки и пробники. [Версии программ, серверный таймер, сохранение, ручная проверка и ограничения баллов](docs/STUDY_SESSIONS.md).

Успеваемость: Задания → Успеваемость. [Расчёты, выборки, закрытая область преподавателя и повторение слабой темы](docs/LEARNING_ANALYTICS.md).

Повторение: Задания → Повторение. [Короткие квизы, работа над ошибками, интервалы, необязательные достижения и отключение наград преподавателем](docs/LEARNING_REWARDS.md).

Родительский доступ: Личный кабинет → Семья. [Подтверждение и отзыв связи, разрешённые учебные данные, комментарии и отдельные события](docs/FAMILY_ACCESS.md).
