# Краткий аудит исходного ZIP «репетитор»

## Итог

Исходный проект — полезный технический каркас, но ещё не готовый «Репет». Визуальную часть требуется заменить почти полностью, а Go-бэкенд разумно сохранить и расширить.

## Что уже есть

- Монорепозиторий.
- Next.js + React + TypeScript frontend.
- Go modular monolith.
- PostgreSQL migrations.
- Пользователи и роли.
- Приглашения ученика.
- Связи «репетитор—ученик».
- Занятия.
- Object-level checks для существующих ресурсов.
- Audit events.
- API-клиент на фронтенде, пока почти не используемый.

## Что не соответствует продукту

- В UI старый бренд `MathPad`.
- Только одна статичная страница `/`.
- Ссылки ведут в `#`.
- Чат не отправляет сообщения.
- Нет `/messages`, `/calendar`, `/tasks`, `/settings`.
- Нет popover уведомлений.
- Нет footer поддержки создателя.
- Навигация не соответствует утверждённым четырём разделам.
- Встречается устаревшая карточка «Материалы».

## Функциональные пробелы backend

- Диалоги и сообщения.
- Read receipts и realtime/polling.
- Задания, submissions и feedback.
- Уведомления и preferences.
- Профильные настройки и сессии.
- Безопасные файлы/вложения.
- Pagination большинства коллекций.

## Риски и исправления

- Dev auth через заголовки нельзя использовать в production.
- При принятии приглашения нужно связать приглашение с email ученика.
- Ошибки важных audit writes нельзя молча игнорировать.
- Нужна UUID/input validation и ограничения длины.
- Нужны deny-by-default и tenant-isolation tests.
- ESLint 9 требует рабочей flat-конфигурации; `next lint` использовать нельзя.
- Следует повторно проверить dependency audit и безопасно обновить цепочку `sharp`.

## Проблема исходного архива

В исходном ZIP были локальные зависимости, build cache, package store, `.git`, macOS metadata и другие генерируемые файлы. Финальный чистый архив должен содержать исходники, lockfiles, миграции, документы и тесты, но не `node_modules`, `.next`, `.pnpm-store`, `.git`, `__MACOSX`, `.DS_Store`, secrets и логи.

Полные требования и порядок реализации находятся в `MEGA_PROMPT_FOR_CODEX.md`.
